Both files are the two photographs of the same navy scrub design shown in the
carousel. Portrait orientation (3:4 or taller) works best — slides are cropped
to a 3:4 frame with `object-fit: cover`. If an image is missing, the carousel
falls back to the ivory `E·O` placeholder panel instead of showing a broken image.
